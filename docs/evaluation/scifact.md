两组 600 次请求均无错误。按 query 对 nDCG@10 的配对差值做 bootstrap，95% 区间为 **+1.33 至 +6.82 个百分点**，改善 / 持平 / 退化为 **76 / 177 / 47**。相似声明之间的相关性可能使按题采样的区间偏窄。

## 实验设计

- 两组使用同一语料、ES 索引和 `qwen3-embedding-4b`。当前发布版默认用本地 `bge-m3`，复跑时记录模型配置并独立报告结果。
- 总候选预算固定为 64。RRF 分配 32 个给词法分支、32 个给向量分支，以 `1 / (60 + rank)` 融合两路名次。标准路径仍保留原 Java 默认的过滤和评分流程。
- 评分前先按文档去重。评测脚本保持固定分母，将请求错误计零。检索延迟为本机温缓存测量，两条分支的响应负载也存在差异。
- [历史逐题排名](../../evaluation/baselines/scifact-2026-11-24.jsonl) 包含 query ID、两组文档排名和相关性标签。已用仓库的 `metrics()` 重新计算并核对上述三个指标。[复跑配置](../../evaluation/configs/retrieval.json)
